# KasssaSysteem

Kassasysteem ontwikkeld om gebruikt te worden op de bieravond van Veros en Scouting Lint.

## Monorepo Structuur

```text
apps/
  frontend/   # React + Vite
  backend/    # .NET Web API
packages/
  ui/         # gedeelde UI modules
  shared/     # gedeelde types/utilities
  config/     # gedeelde configuratie modules
```
